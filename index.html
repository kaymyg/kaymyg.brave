What I'm building

Governance infrastructure for agents that write code unsupervised.

Two connected projects: one contains an agent's blast radius at runtime, the other scores its behavior across a session.

lean-agent-governance

active · v8.0

A drop-in governance layer for AI coding agents. Sandboxes execution in a read-only host / read-write tmpfs split, caps patch size before anything reaches git apply, enforces session timeouts, and normalizes prompt-injection detection against zero-width and bidi-override smuggling. A forward-looking x402 protocol integration patch is prepared and staged — interface stubs only, waiting on live infrastructure before activation.

kaysentinel

early-stage · formal spec + partial implementation

A post-execution authorization framework for state-machine systems like Ethereum. Lifts execution traces into a canonical Structural Sufficient Representation (SSR) and evaluates policy over that quotient space, so authorization decisions don't depend on which client — Geth, Reth — produced the trace.

Formal specification is complete. Rust reference implementation has the canonical event ABI done (cse), the builder pipeline in progress (builder — partition → reduce → lifecycle resolution → certificate assembly, 21 passing tests), and domain-separated BLAKE3 commitments as a working primitive (hash, 8 passing tests, not yet cross-language-verified). SSZ encoding, storage-trie derivation, and the client extractors are still empty stubs.
